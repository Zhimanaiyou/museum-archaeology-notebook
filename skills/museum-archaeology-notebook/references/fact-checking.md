# 文物事实核验

## 信息优先级

1. 用户照片中清晰可读的展签。
2. 用户明确提供的信息。
3. 收藏或展出该文物的博物馆官方网站。
4. 正式考古报告、学术机构资料或可靠馆藏数据库。
5. 其他网络来源只能作为线索，不能压过一手资料。

## 执行原则

- 先判断哪些信息会实际进入画面，只核验这些关键字段。
- 名称无法确认时使用有依据的类别名称，如“刻辞卜甲”“玉刀”，不要猜具体器名。
- 年代只能确认到较宽范围时，保留宽范围，不擅自缩窄。
- 出土地点、墓号、编号、尺寸和释文必须有清晰依据；缺少依据就省略。
- OCR 结果只是候选文本。铭文、甲骨文字和模糊展签必须回看原图，不直接采信 OCR。
- 不对难辨铭文作自由释读，不根据外形编造用途、祭祀含义或历史故事。
- 网络搜索按需停止：一个非关键字段若经过少量高质量来源仍无法确认，就省略。

## 画面中的不确定性

优先省略不确定信息。确有必要保留时，使用“待考”“或为……”或“据展签”等清楚限定，不使用看似确定的陈述。
