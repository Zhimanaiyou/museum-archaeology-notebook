# 图像制作流程

## 角色分工

- 原照片：唯一的真实摄影层，直接由文件合成。
- 图像生成能力：只制作旧纸、胶带、铅笔质感或可核对的辅助线稿，不负责重画真实照片区域。
- 程序合成：控制画布比例、原图放置、中文文字、局部裁切和 PNG 输出。

## 推荐步骤

1. 查看原图并记录方向、尺寸和主体边界；另存输出，永不覆盖输入。
2. 先确定 3:4 或 4:3，再给真实照片预留约半张画布。
3. 默认使用 `contain` 完整容纳照片。只有用户允许且不会切掉文物主体时，才使用覆盖式裁切。
4. 铭文、纹饰、裂纹和修复痕迹的局部观察框直接裁取原图，不让图像模型重建。
5. 整体线稿有三种优先级：可靠的人工或馆方线图；从原图机械提取的边缘线稿；以原图为参考生成并逐项核对过的铅笔线稿。
6. 若使用内置图像生成能力，把输入图片明确标为“参考图”，要求只生成独立的线稿或纸张素材，并反复声明不可增加结构、纹饰或铭文。
7. 使用 `scripts/compose_notebook.py` 完成最终合成和中文渲染。其机械线稿回退不会理解或补全考古细节。
8. 保存 PNG 后重新打开检查，确认主体没有被切断、文字可读、文件真实存在。

## 生成提示骨架

```text
用途：考古研究手记中的独立铅笔线稿素材
输入图片角色：器物事实参考，不是可自由改造的风格参考
主体：只画照片中清楚可见的器形轮廓与结构
媒介：克制的铅笔考古手稿，暖白纸或透明背景
约束：不得增加、补全、改写任何纹饰、铭文、裂纹或器物结构；看不清的区域留空；无文字；无水印
```

## 能力不可用时

不要改用未经同意的付费 API。使用脚本的机械边缘线稿和简单纸张纹理完成可执行的基础版，并明确说明其艺术性较弱、仍需人工审美检查。
